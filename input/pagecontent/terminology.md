Terminology is a critical aspect of quality measurement and reporting. Measure specifications and associated FHIR resources and profiles identify the value sets, code systems, and terminology bindings required for measure evaluation and reporting. Additional guidance on the appropriate use and management of terminologies should be obtained from [HL7 Terminology (THO)](https://terminology.hl7.org/en/index.html) and the authoritative terminology publishers. See [*External Code Systems*](https://terminology.hl7.org/en/external_code_systems.html) in HL7 Terminology (THO) for more information.

Measure collections are often developed and published together with explicit listings of the versions of the value sets and code systems that are expected to be used with the measures. Refer to the [Version Manifest](https://hl7.org/fhir/uv/crmi/en/version-manifest.html) topic in CRMI for more information on how this can be done in FHIR.
